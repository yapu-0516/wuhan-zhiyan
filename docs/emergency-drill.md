# 城市应急演练

独立入口：`/drill`

## 定位

应急演练与“城市总览”的实时监测逻辑分开。进入页面后先展示平静城市：

- 约 800 名模拟人员，分布在事件候选区域和城市中心；
- 约 400 辆动态车辆，沿现有道路移动；
- 不展示历史事件、异常弹窗和处置队列；
- 一次演练只允许一个活动事件。

## 交互闭环

1. 在平静页选择一种固定演示场景并点击“启动当前场景”；
2. 镜头飞往事件位置，显示风险半径、算法指标和空间影响；
3. 汇总风险范围内模拟人员、车辆和关联建筑；
4. 点击“开始疏散”，风险内人员先进入反应等待状态，再分批沿现有道路离开；
5. 点击“派发处置”，在事件附近生成消防或救援人员并向风险区移动；
6. 点击“结束并复位”，清除事件并重新生成平静基线。

演练启动后会创建 `DR` 运行记录，并关联独立的 `SC` 情景会话和 `SV` 情景版本。
过程指标与时间线持续更新，结束时保存回放帧并生成 `drill` 复盘草稿。
可通过 `?eventId=E0001` 带入现有事件、`?scenarioSessionId=SC...` 带入情景参数，
或通过 `?runId=DR...` 恢复已完成演练的聚合记录。

## 事件种子

种子来自现有演示事件，运行时不沿用历史时间，而是复制事件类型、算法指标、
位置和处置语义：

| 类型 | 来源事件 | 演练场景 |
| --- | --- | --- |
| 建筑火情 | E0049 | 万达商业广场疑似火情 |
| 交通拥堵 | E0032 | 香港路严重拥堵 |
| 道路积水 | E0024 | 建设大道路面中度积水 |
| 建筑异常 | E0045 | 中环大厦-A座墙体开裂 |

## 数据边界

- 人员和车辆数量、轨迹、疏散进度和处置人员均为模拟数据；
- 风险半径用于演练展示，不是专业火势、洪涝或结构安全模型；
- 人员优先出现在现有道路两侧约 2–4 m 的偏移位置，这只是近似人行道表现；
- 人员具有类型化步行速度和 0.15–6.5 秒不等的反应延迟，邻近拥挤时会轻度降速；
- 人员之间采用局部间距分离，但不是完整社会力或 ORCA 模型，仍可能穿越建筑；
- 车辆只沿现有道路折线行驶，事件附近会减速或停车；
- 风险半径按事件类型随时间平滑扩大，疏散期间每 4 秒重新计算路线；
- 交通拥堵场景不会启动人员疏散，只展示车辆减速和拥堵处置；
- 交通场景中车辆在事件外围减速、核心区排队；点击“启动交通疏导”后生成临时绕行路径，
  右侧切换为平均车速、排队、受影响和累计绕行指标。
- 当前使用道路中心线构建临时连通图，并以风险加权 Dijkstra 选择风险区外道路节点；
- Demo 收敛为最多 4 个出口，使用 1.2–2.2 人/秒的临时服务率，不代表真实出口容量；
- 真实步行网络、道路宽度、方向、封路传播、替代路线和资源 ETA 仍需 B 提供；
- 演练记录、情景版本、回放帧和复盘草稿已接入业务闭环；

## Demo 演示增强

- 平静页提供火灾、内涝、建筑异常、交通拥堵四个固定场景，不再依赖随机抽取；
- 顶部提供 1× / 4× / 8× 倍速，默认使用 4×；
- 风险扩大期间每 4 秒动态重规划，地图同步绘制代表性路线和高风险路段；
- 核心风险区路段显示为封闭路段，受影响车辆沿临时安全路径绕行；
- 右侧固定区域显示最近两条推演事件、当前风险半径、重规划次数和启用出口数；
- 疏散结束后显示完成时间、峰值排队和主要瓶颈出口；
- 应急演练保留独立入口；城市总览的一键演示改为随机异常、AI 研判、情景推演和异常增多监测故事线。
- Windows 可直接双击 `start-demo.cmd`，自动检查构建、启动后端并打开浏览器。
