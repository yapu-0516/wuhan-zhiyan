# 5 分钟路演脚本

> 适用场景：项目答辩、比赛路演、客户演示。建议 1920×1080 全屏，Chrome / Edge 最新版。
> 演示前：`make demo`（或 `docker compose up`）启动，浏览器打开 <http://localhost:8000>，确认右上角显示「实时连接」。

| 时间 | 画面 | 操作 | 讲解要点 |
| --- | --- | --- | --- |
| 0:00 | 城市总览 | 打开首页，停留 5 秒 | 「这是武汉汉口沿江示范区的数字孪生底座：上千栋 **OpenStreetMap 真实建筑**、主干路网和长江岸线，左侧是城市安全指数与实时路网指数。」 |
| 0:20 | 城市总览 | 点击顶部 **一键演示** | 系统自动运镜：俯冲入城 → 环绕 CBD → 打开实时路况图层。「路网颜色每 10 秒按交通指数 TPI 刷新，算法依据国标思路把车速折算为 0–10 的拥堵指数。」 |
| 1:00 | 火情告警 | 导览自动触发火灾场景 | 「无人机巡检帧刚刚送入 FlameNet-Lite 火焰识别算法——注意，事件是否产生**完全由算法实际运行结果决定**。」相机自动飞向告警点，三维涟漪 + 右侧事件流弹出新事件。 |
| 1:40 | 事件详情 | 查看证据图 | 「这是算法输出的标注证据图：红框为火焰区域，置信度、火焰像素占比、烟雾评分都可追溯。」点击 **派单处置**，选择「江汉区消防救援大队」。 |
| 2:20 | 事件中心 | 左侧导航进入 **事件中心** | 「所有终端通过 WebSocket 同步，刚才的派单已经写入处置时间线。事件遵循 待核查 → 监测中 → 处置中 → 已办结 的状态机，非法流转后端直接拒绝。」 |
| 3:00 | AI 分析 | 进入 **AI 分析**，选择「建筑异常检测」→ 示例数据「加速沉降监测点」→ 开始分析 | 「Theil–Sen 稳健趋势 + 二次拟合加速度 + MAD 异常点，判定为预警。」展示沉降曲线与阈值线，点击 **在三维场景中查看**。 |
| 3:40 | 城市监测 | 进入 **城市监测** | 「无人机、卫星、视频、物联传感四类数据源的在线率和实时吞吐，最拥堵路段排行实时滚动，建筑安全监测清单按风险排序。」 |
| 4:20 | 数据管理 | 进入 **数据管理** | 「平台管理的空间数据资产：遥感影像、倾斜摄影、OSM 矢量……支持拖拽上传入库。」 |
| 4:40 | 城市总览 | 回到首页，**复位视角** | 总结：「感知—识别—研判—处置—复盘全闭环；算法可插拔替换为深度学习模型；后端断开时前端自动降级为离线快照模式，演示永不翻车。」 |

## 演示备忘

- **随时制造事件**：总览页工具栏「一键演示」，或调用 `POST /api/demo/scenario {"scenario":"fire|traffic|building|flood|random"}`。
- **重置数据**：`POST /api/demo/reset`，或删除 `backend/var/cityeye.db` 后重启。
- **网络不佳**：图层面板切换「离线底图」，所有三维数据均来自本地后端，不依赖外网。
- **后端意外退出**：前端自动进入「离线演示」模式（顶部琥珀色提示），可继续浏览全部页面。
- **节奏控制**：模拟器默认约 45 秒执行一次巡检，可通过 `CITYEYE_SIM_INTERVAL` 调整。
