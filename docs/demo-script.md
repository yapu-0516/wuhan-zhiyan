# 5 分钟路演脚本

> 适用场景：项目答辩、比赛路演、客户演示。建议 1920×1080 全屏，Chrome / Edge 最新版。
> 演示前：`make demo`（或 `docker compose up`）启动，浏览器打开 <http://localhost:8000>，确认右上角显示「实时连接」。

| 时间 | 画面 | 操作 | 讲解要点 |
| --- | --- | --- | --- |
| 0:00 | 城市总览 | 打开首页，停留 5 秒 | 「这是武汉汉口沿江示范区的数字孪生底座：上千栋 **OpenStreetMap 真实建筑**、主干路网和长江岸线，左侧是城市安全指数与实时路网指数。」 |
| 0:20 | 平静城市 | 点击顶部 **一键演示** | 首页默认不展示历史异常，只显示道路、建筑、持续流动的人群和车辆。「系统先保持平静基线，再随机注入一个真实算法可检出的异常。」 |
| 0:40 | 数字孪生 | 导览自动运镜 | 系统俯冲入城并环绕 CBD，展示 OSM 建筑、路网和城市运行指标。 |
| 1:10 | 随机异常 | 导览随机选择火灾、交通、积水或建筑异常 | 「巡检系统随机抽取风险类型，是否产生事件由对应算法实际运行结果决定。」相机飞向异常点，三维场景和事件流只显示本次演示事件。 |
| 1:40 | 响应过程 | 导览自动派单 | 展示事件证据、置信度和处置单位，事件进入「处置中」，形成可追溯时间线。 |
| 2:10 | AI 追问 | 导览打开城市治理助手并自动提问 | 「围绕当前异常询问未知信息、优先核实事项和周边设施关注点，回答只使用事件目录与空间数据。」 |
| 2:50 | 虚拟推演 | 导览打开情景推演并输入一句话 | 生成常规响应、不利响应和提前干预三套结果，同步展示风险范围、道路影响和模拟人员变化。 |
| 3:40 | AI 分析 | 导览进入对应风险分析页并自动提交示例数据 | 展示真实算法运行结果、检测指标和趋势曲线，检出异常时自动生成事件。 |
| 4:20 | 异常增多 | 导览返回总览并连续触发多类风险 | 「假设异常同时增多，指挥中心统一汇聚新增事件、类型分布、风险等级和处置状态。」 |
| 4:50 | 监测闭环 | 停留总览 | 总结：「平静基线 → 随机异常 → 响应 → AI 研判 → 推演 → 算法分析 → 异常增多监测，形成城市运行闭环。」 |

## 演示备忘

- **一键演示**：总览页工具栏「一键演示」会保留前两步城市感知与数字孪生，再依次完成随机异常、派单、建筑预警、AI 追问、情景推演、AI 分析和异常增多监测。
- **自动恢复基线**：每次点击「一键演示」前会恢复固定种子数据，清除人工上报、历史任务和上次演示产生的事件。
- **单独演练**：进入 `/drill`，固定选择火灾、交通、积水或建筑异常，按 1× / 4× / 8× 倍速运行。
- **重置数据**：`POST /api/demo/reset`，或删除 `backend/var/cityeye.db` 后重启。
- **网络不佳**：图层面板切换「离线底图」，所有三维数据均来自本地后端，不依赖外网。
- **后端意外退出**：前端自动进入「离线演示」模式（顶部琥珀色提示），可继续浏览全部页面。
- **节奏控制**：模拟器默认约 45 秒执行一次巡检，可通过 `CITYEYE_SIM_INTERVAL` 调整。
